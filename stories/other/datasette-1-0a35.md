Datasette 1.0a35 releases major table management features: a "Create table" UI backed by JSON API supporting columns, keys, defaults, and constraints; "Alter table" actions for modifying existing tables; and stable, documented template context API. These capabilities expand Datasette from read-only database viewer to full CRUD operations, advancing toward its 1.0 stable release.
