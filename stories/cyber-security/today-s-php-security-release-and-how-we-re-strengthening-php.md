If you run PHP, upgrade now. Today's release across the PHP 8.x line fixes two remote code execution holes, and exploits were already circulating. The CVE IDs leaked on October 20 with a wrong release time and a CVSS score of 10.0, when the real score is 9.2. Calif then mistakenly published a video of its proof of concept working against targets, which sped up exploit development. The PHP Foundation moved its release up a day.
