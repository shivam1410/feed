A new method distills world-model knowledge into compact Vision-Language-Action robot policies, combining physical grounding with real-time performance. A 0.8B parameter student model achieved 97.9% success on LIBERO and improved humanoid manipulation from 48.2% to 50.5% on RoboCasa-GR1. The deployed policy runs in 32 milliseconds using only 1.86 GB memory on consumer hardware. Gains persist across changes in model scale and architecture, indicating the approach captures a robust representational principle rather than fragile alignment between specific networks.
