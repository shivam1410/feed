WIZARD is a weight-space meta-learning framework that adapts frozen Vision-Language Action (VLA) policies by generating task-specific LoRA parameters from language instructions and demonstration videos. Without fine-tuning the base model, the framework efficiently specializes policies for new manipulation tasks. This approach reduces computational overhead while maintaining flexibility, enabling robots to quickly learn new skills from language-guided demonstrations. This matters because robot learning traditionally requires significant compute and extensive task-specific data collection. WIZARD achieves efficient specialization with minimal additional training, making multi-task robot systems more practical and accessible.
