Using Koopman operator theory, this work establishes the first identifiability framework for mechanistic interpretability circuits in neural networks. The spectrum of the lifted linear realization is coordinate-free and recoverable from M calibration samples at rate M^-1/2 with matching minimax lower bounds. The work proves variance-carrying and information-carrying directions cannot coincide in non-normal realizations. This provides theoretical foundations for determining which interpretability findings reflect true model properties versus experimental artifacts.
