X-Planner is a planning front-end for embodied AI that structures reasoning as discrete interpretable event states and continuous chain-of-thought states. Training data combine Ego, UMI, and teleoperation with variable annotation depth and human-designed failures for error recognition. On real-robot experiments it outperformed baselines. This matters because explicit planning structure helps embodied agents communicate and improve long-horizon reasoning.
