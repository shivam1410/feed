There is growing interest in using CGM for purposes other than those initially intended. Recent work of Lobo et al. identified $\Omega$: a set of motifs such that almost any daily CGM profile (the 24-hour CGM time series starting at midnight) can be classified - matched to a motif in $\Omega$. This work generalizes the prior work by identifying sets of motifs for 4-, 6-, 8-, 12-, and 24-hr CGM profiles where an $x$-hr CGM profile does not have to be 24 hours in length, and does not have to start at midnight. The prior work methods are modified to identify the five new sets of motifs using data from the same 6 studies in the original work. The newly identified sets were subjected to rigorous external validation using a data set comprised of data from 21 studies (3,455 subjects, 289,592 days of CGM data). The external validation data set has both temporal and geographic transportability and addresses limitations of the data set used to define the five new sets of motifs. The results of the external validation indicate that the prior work generalizes well: the performance of each $x$-hr set of motifs on the external validation set is almost identical to that obtained for $\Omega$. The generalization of the original work broadens the potential use cases of the framework to include short term predictions (e.g., impending hypoglycemia) and diagnostics which rely on detecting changes in CGM time series which are less than 24 hours in length.
