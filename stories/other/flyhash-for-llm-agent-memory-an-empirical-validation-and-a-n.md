FlyHash, a fruit-fly-inspired locality-sensitive hashing method, improves neighbor-structure preservation over SimHash for large language model agent memory retrieval under matched-bit protocols and genuine relevance labels, but it does not provide practical memory or latency advantages over SimHash or HNSW at ordinary scale.
