OpenAI's GPT-6.1 Terra is a fast, efficient model built for visual reasoning and computer use. It steps up from GPT-5.6 Terra and writes more clearly. Ted Sanders of OpenAI says it is similar to Astra and Sol on vision and computer use, but much faster. It is a bit weaker on most other tasks. For API users, it sits between the cheaper Luna and the pricier Sol. For subscribers, the writer calls it a modest update, mainly useful if you hit usage limits.
