A conditional generative framework encodes brain connectomes into a compact latent space capturing both structure and computation. Achieves edge reconstruction with AUC 0.910 and functional prediction R² ~0.87, revealing task-specific mechanisms: memory correlates with reciprocal connectivity while prediction favors distinct structures. This bridges connectome structure to function in neural circuits.
