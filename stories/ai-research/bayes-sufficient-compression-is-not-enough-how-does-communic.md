When agents communicate, short messages sometimes help and sometimes hurt. This framework reveals that message utility depends on what the receiver can actually execute, not just whether the message contains correct information. The same communication protocol raised accuracy from 0.633 to 0.775 on one task but dropped it from 0.889 to 0.653 on another. Design matters more than theory predicts.
