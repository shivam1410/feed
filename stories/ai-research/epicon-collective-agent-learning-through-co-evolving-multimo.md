EpiCon enables agent collective learning through a shared multimodal memory without updating model weights. A frozen memory bank from one agent immediately improves others, while a self-organizing consolidation system builds hierarchies of lessons. Across eleven benchmarks in four domains, memory sharing gains 1.7 to 4.9 points per system while cutting memory overhead by two-thirds.
