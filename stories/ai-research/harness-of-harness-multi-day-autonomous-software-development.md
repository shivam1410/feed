Harness-of-Harness enables autonomous coding agents to make continuous improvements to software through structured planning-coding-testing loops operating over multiple days. The system produces substantial performance gains and fully developed working applications without manual intervention between cycles. This capability represents significant progress toward true autonomous software development, where AI systems can incrementally refine codebases through structured self-improvement processes. The approach combines automated planning with code generation and validation, allowing agents to identify improvements, implement them, and verify correctness in repeated cycles. Autonomous agents can maintain code quality and functionality while progressively enhancing capabilities.
