DELBERT-2 is a pretrained model that turns molecular fingerprints into token sequences. It was trained with masked language modelling on 2.5 million molecules. On top-100 enrichment it scores 13.28 against 12.36 without pretraining, a 7.4% gain. That is about 13 times better than random selection. The biggest gains appear in the hardest out-of-distribution tests. Code is on GitHub.
