InFlowOp optimizes multi-agent workflows using one unified cost metric that weighs agent competence against runtime. It adjusts task granularity and agent assignment before execution and fixes faults during runtime with the cheapest available move. Across various domains and models it improved single-agent baselines by up to 11.97% and achieved 9.64% additional gain with in-flow optimization, outperforming fixed templates.
