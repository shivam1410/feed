Matthew Green sketches a plausible worm scenario: isolated agents leave malicious instructions in shared package caches, and downstream agents execute them. He notes the same vulnerability could exist with personal cloud agents communicating via email, Slack, or shared documents. This isn't theoretical, it's a design flaw waiting to be exploited.
