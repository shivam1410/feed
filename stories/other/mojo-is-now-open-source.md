Mojo, a Python-inspired language optimized for GPU programming, released version 1.0 and opened its compiler and toolchain under Apache 2 license after promising open source since May 2023. Originally designed as a Python superset, Mojo evolved into a distinct language. AI tools already assist in migrating Python code to Mojo.
