Attackers compromised Microsoft's agent-framework package on PyPI. Versions 1.26.1 and 1.26.2 were published 33 minutes apart on November 17, 2026. They carry a credential stealer that runs every time Python starts. Several security firms, including Wiz and Socket, reported it. The malware targets cloud credentials. Anyone who installed those versions should treat their cloud secrets as exposed.
