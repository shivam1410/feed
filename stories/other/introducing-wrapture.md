Wrapture, a new Python library from Graham Dumpleton (renowned for creating wrapt, mod_wsgi, and New Relic's Python agent), extends monkeypatching capabilities for simultaneous testing and tracing of any function or method without source code modification. The library offers configuration-based tracing mechanisms for existing Python projects, includes built-in OpenTelemetry support for integration with observability platforms, and enables comprehensive observation and behavior override capabilities. Notably, the entire codebase and all documentation were created by an AI assistant working under Dumpleton's direct supervision, demonstrating the viability of AI-driven software development on substantial projects. Though just weeks old, the project shows very promising early results.
