Simon Willison created CORS Chat, a web-based interface specifically designed for testing OpenAI-compatible chat endpoints with both locally-run and remote language models. Built with advanced reasoning capabilities, the tool supports locally-executed models like Qwen 3.8 27B running on Mac and NVIDIA hardware, as well as remote services such as OpenRouter and LM Studio instances. Conversations are automatically persisted in the browser with full JSON export capability for archival and analysis purposes. A particularly innovative feature detects SVG image outputs and progressively renders them during token streaming, enabling developers to preview graphical outputs in real-time without waiting for generation to fully complete.
