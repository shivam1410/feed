Researchers built MC-Lens, a tool that shows which concepts a vision-language model actually accesses inside. It maps both the vision encoder and the language decoder into one shared vocabulary space, so image and text concepts can be compared directly. Counterfactual tests show those accessed concepts feed into later reasoning. Two new metrics track cross-modal alignment more clearly than hidden state cosine. It matters because it checks whether a model's internal concepts truly drive its answers.
