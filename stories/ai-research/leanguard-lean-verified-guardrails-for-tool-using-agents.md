LeanGuard is a runtime guardrail for AI agents that use tools. It blocks tool calls that break policy, and it can repair them using proof-guided search. The guard is Lean-verified. The work reports fewer unauthorized executions and fewer successful prompt injections. Normal task performance was not harmed.
