Researchers built Learn2Play Bench, a benchmark of text-based games with novel rules to test whether LLM agents actually learn from experience. They found that keeping full records of actions beats summarizing into rules, humans outperform agents by exploring more varied strategies, and the agent harness itself matters for learning ability. This helps distinguish real learning from using existing knowledge.
