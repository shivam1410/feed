AutoDesign employs a meta-harness optimizer to recursively improve code agents for structured media generation tasks such as paper-to-poster synthesis. The system automatically refines the agent's execution harness rather than modifying the underlying model. The approach achieved state-of-the-art results on paper-to-poster synthesis benchmarks, demonstrating that agent performance can be systematically improved through automated optimization of execution harnesses.
