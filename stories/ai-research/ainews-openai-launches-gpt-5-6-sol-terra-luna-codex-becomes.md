OpenAI released GPT-5.6 in three sizes—Sol, Terra, and Luna—with a new ultra effort level that coordinates four parallel agents by default for complex tasks. Terra performs just above Fable 5 while Luna outperforms Opus 4.8, each achieving results in roughly one-third the time, using about half the output tokens, and costing approximately one-quarter as much as the previous models. The release sets new state-of-the-art results on Terminal-Bench 2.1 and DeepSWE, which test complex command-line reasoning. Additionally, Meta's Superintelligence Labs launched Muse Spark 1.1 with Model API access, signaling confidence in deployment and third-party testing. This matters because it improves performance-cost efficiency while enabling parallel agent coordination for more complex reasoning.
