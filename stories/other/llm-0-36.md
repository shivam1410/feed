The llm command-line tool released version 0.36 with full support for OpenAI's new GPT-6 Sol and Luna models. A key improvement: model plugins can now declare whether they support multi-turn conversations. If you use conversation history with a single-turn-only model, llm raises a ConversationNotSupported error before it causes problems. This helps developers avoid integration mistakes when switching between models with different conversation capabilities.
