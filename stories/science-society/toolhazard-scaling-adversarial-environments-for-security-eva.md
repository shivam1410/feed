ToolHazard is a scalable framework that synthesizes adversarial environments to test LLM agents against indirect prompt injection attacks. The system reveals vulnerabilities in agent defenses and generates evidence for improving defensive alignment. Multi-scenario testing exposes weaknesses across different attack vectors. This matters because prompt injection is a real attack vector affecting deployed agents in production systems.
