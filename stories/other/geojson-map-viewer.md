A web tool for displaying and exporting GeoJSON map files as PNG images, built iteratively with Claude Code and Fable 5.1. It visualizes local political boundaries for the Granada Community Services District and Midcoast Community Council near Half Moon Bay, California. Both datasets were generated by ChatGPT Work by extracting and combining government data sources. The tool fills a practical need for interactive boundary viewing and static image sharing.
