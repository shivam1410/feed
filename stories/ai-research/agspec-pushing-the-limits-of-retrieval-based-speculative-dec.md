AgSpec improves speculative decoding for coding agents by retrieving code from session, workspace, and global corpora. It raises generation throughput up to 4.37 times at batch size one and 4.76 times at batch sixteen compared to standard autoregressive decoding. Coding agents generate code much faster by reusing existing context from their workspace and prior attempts.
