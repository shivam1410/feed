Researchers developed PIMiner, an agentic system to test LLM agent security by attempting prompt injection attacks, where adversaries manipulate system instructions through user input. PIMiner builds a strategy library from training on various target models, then transfers efficiently to new unseen models with minimal queries. Testing shows high attack success rates: 76.2% against Gemini-2.5-Pro, 61.9% against GPT-5.1, and 42.9% against Claude-Sonnet-4.5. This red-teaming approach identifies vulnerabilities and generates training data for improving agent defenses.
