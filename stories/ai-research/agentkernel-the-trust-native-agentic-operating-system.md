AgentKernel is an operating system for AI agents that enforces mandatory security across identity, input sensing, memory, and execution. Unlike existing application-level middleware, the kernel creates a non-bypassable boundary against prompt injection, memory poisoning, delegation abuse, and tool misuse. It treats security as a capability multiplier. This matters because agents that cross trust boundaries need OS-level guarantees, not just middleware.
