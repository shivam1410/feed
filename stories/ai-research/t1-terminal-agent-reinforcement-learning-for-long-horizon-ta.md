T1, a 122-billion parameter Mixture-of-Experts language model, was trained with reinforcement learning to execute long-horizon terminal tasks in a cloud sandbox environment. The model uses stable actor-critic optimization and out-of-distribution training scenarios to improve robustness. T1 demonstrates state-of-the-art performance on complex multi-step terminal tasks requiring sustained reasoning and planning. The system must understand task objectives, break them into executable steps, and adapt to unexpected conditions—capabilities representing a step forward for AI agents. This work illustrates how reinforcement learning combined with large-scale models can produce agents capable of executing extended, real-world-like tasks.
