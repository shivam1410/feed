Enfold achieves fast embodied control by internalizing future-generative computation into present-only representations rather than running predictive models repeatedly at each control step. This approach pre-computes and encodes forward-looking capacity directly into current state representations, eliminating the computational overhead of repeated inference during real-time control loops. The method enables rapid decision-making in interactive environments without sacrificing predictive performance accuracy. By folding forward-looking computation into instantaneous state representations, Enfold addresses a fundamental computational bottleneck in predictive control systems. This innovation makes ultra-efficient real-time control practical for robotics and embodied AI applications where latency reduction critically improves performance and system responsiveness in dynamic environments.
