RynnValue is an open-source value foundation model for robotic manipulation that learns generalizable value predictions using temporal distance rather than explicit human preferences or progress metrics. By grounding value learning in temporal relationships between states, RynnValue improves real-world policy success rates. This approach enables robots to autonomously evaluate action quality, scaling value learning across diverse manipulation tasks without manual reward engineering.
