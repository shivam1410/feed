Functional Attention reframes attention mechanisms as correspondences between adaptive functional bases, enabling more compact and resolution-invariant learning for operator approximation. The approach proves effective for solving partial differential equations and 3D segmentation—tasks requiring operators across different scales. By treating attention as functional correspondence rather than pairwise token relationships, models achieve smaller size without sacrificing accuracy across varying input resolutions. This abstraction reduces model size and computational requirements while maintaining generalization. The innovation demonstrates how rethinking fundamental components improves deep learning efficiency.
