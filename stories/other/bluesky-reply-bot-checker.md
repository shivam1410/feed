Simon Willison built a Bluesky reply bot detector using Claude Opus 5.5. The tool identifies bots by looking for rapid-fire replies posted within seconds, accounts that never create original content, and consistent replies to high-follower users, especially those ending with unnecessary question marks. It helps combat automated reply spam that's migrating to Bluesky from Twitter.
