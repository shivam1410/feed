Created interactive test harness combining OPFS (Origin Private File System) with Pyodide to explore whether Datasette Lite—Datasette running entirely in browser via WebAssembly—can edit persistent SQLite files stored on user computer. Playground UI allows testing OPFS functionality across different browsers. Addresses open question about feasibility of browser-based persistent database editing without server infrastructure.
