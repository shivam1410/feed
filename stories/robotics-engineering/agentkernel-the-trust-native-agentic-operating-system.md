AgentKernel is an operating system for AI agents that treats security as a first-class design constraint. It wraps the agent lifecycle in four pillars: Identity, Perception, Cognition, Execution. Each pillar defends against semantic attacks like prompt injection and memory poisoning. It provides mandatory, non-bypassable enforcement. This matters because agents cross trust boundaries by default, and current governance is just middleware.
