Running Guide is an AI agent providing real-time audio navigation and obstacle detection to enable blind and low-vision (BLV) athletes to run independently. The system processes environmental information and communicates it through audio cues, allowing athletes to navigate routes without sighted assistance. This technology is significant because it addresses a major barrier to independent outdoor activity for BLV individuals, expanding accessibility for athletic participation and demonstrating how AI supports physical activity.
