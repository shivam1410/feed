Chinese AI lab Z.ai released GLM-5.2, a 753-billion parameter open-weights text-only LLM with 1 million token context (up from 200k in GLM-5.1). It ranks #1 on Artificial Analysis Intelligence Index (score 51) and #2 on Code Arena WebDev leaderboard, outperforming many closed models. However, it is token-hungry, consuming 43k output tokens per task versus competitors' 24k-37k. Released under MIT license, it represents the most capable open-weights text-only model available.
