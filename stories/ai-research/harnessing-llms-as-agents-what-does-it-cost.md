LAM measures the hidden computational cost of running AI agents by modeling memory, context, and recomputation. The framework shows bit-reversal tasks require Θ(n²/(C+S)+n) model calls given context and memory size, deriving optimal checkpoint strategies. Tests on GPT-6 Astra confirmed predictions for communication, reliability, and verification costs. This matters because agent systems incur hidden costs; quantifying them reveals where optimization helps most and guides system design.
