Attackers compromised Microsoft's agent-framework package on PyPI to push a credential stealer. Versions 1.26.1 and 1.26.2 went out 33 minutes apart on November 17, 2026. The malicious code runs on every Python start and targets cloud credentials. Several security firms, including Socket and Wiz, reported it. Anyone who installed those versions should check their systems and credentials.
