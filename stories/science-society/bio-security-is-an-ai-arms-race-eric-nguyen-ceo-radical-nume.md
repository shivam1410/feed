DNA language models like Evo can generate functional virus genomes by exploiting long context windows to handle biological sequence length. An Arc/Stanford team synthesized computationally designed bacteriophage genomes that actually became working viruses. The tension: these same frontier models unlocking biological capability pose serious biosecurity risks, so defensive capabilities need to keep pace.
