Researchers using genomic language models like Evo can generate functional virus genomes from scratch and synthesize them into living viruses. These models handle DNA's 4-letter alphabet and extremely long sequences up to 3 billion characters for the human genome. This creates an arms race where the same AI enabling biological creation can improve defenses, with capabilities scaling alongside frontier models.
