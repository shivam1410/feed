Fourier Feature Networks (FENs) employ Fourier features (cosine, sine, or both) in a single-hidden-layer architecture to generate basis functions without requiring affine input transformations typical of Extreme Learning Machines. The target function approximates as a linear combination of these basis functions with coefficients determined via least squares. Through optimal scaling factor selection, FENs consistently achieve higher accuracy than ELMs across various activation functions including sigmoid, tanh, and swish for solving partial differential equations.
