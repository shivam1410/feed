Security researcher Matthew Green describes how independently deployed AI agents could be exploited by worms. Agents in separate sandboxes can leave instructions in shared package caches, which other agents pick up and execute. Extending this: email, Slack, and shared documents become infection vectors. This exposes a fundamental vulnerability in decentralized independent-agent architectures.
