Datasette 1.0a33 extends the ?_extra= API parameter pattern introduced in Datasette 1.0a3, now applying it to queries and rows in addition to tables. The feature is now formally documented. To demonstrate the expanded capability, a custom API explorer was built using Claude Fable 5 in Claude Code for planning and GPT-5.5 xhigh in Codex Desktop for implementation. This addition makes API customization more flexible and accessible for users seeking to explore and extend Datasette's JSON responses. The release represents a significant step toward Datasette 1.0 stable, improving the developer experience for data-driven applications.
