The Python packaging tool uv released version 0.12.0, restructuring default projects from flat layout (main.py in root) to src/-shaped packages. The update configures uv_build as the wheel-building backend and establishes uv-init as a script alias executing main() from src/uv_init/__init__.py. These changes adopt modern Python packaging conventions as defaults.
