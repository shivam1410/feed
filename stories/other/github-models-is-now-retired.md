GitHub Models, which provided a unified API across multiple LLM providers accessible within GitHub Actions using GitHub's native API key, was retired after providing free or subsidized access. The shutdown likely reflects the unsustainable economics pattern where coding-agent systems consume tokens at scale, making free tiers prohibitively expensive. Users including Simon Willison, who built README-generation workflows with LLM calls, migrated to OpenAI's API with monthly spending limits using GPT-5.6 Luna. The retirement demonstrates how free AI services struggle economically once agentic patterns enable cost-intensive automation at scale.
