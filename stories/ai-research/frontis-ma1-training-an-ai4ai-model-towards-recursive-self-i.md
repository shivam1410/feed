Frontis-MA1, a 35-billion-parameter model, demonstrates recursive self-improvement by learning to improve machine learning engineering itself. Using the OpenMLE framework with four program-evolution operators (Draft, Improve, Debug, Crossover), it improves performance from 39.39% to 60.61% on MLE-Bench Lite with a 12-hour budget per task on a single RTX 4090 GPU capped at 12GB VRAM, approaching state-of-the-art capabilities.
