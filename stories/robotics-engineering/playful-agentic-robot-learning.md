Embodied robots learn reusable skills through self-directed play and exploration, then apply these learned skills to improve performance on downstream tasks without requiring any additional training. This demonstrates that autonomous learning through environmental interaction produces genuinely generalizable capabilities. The approach suggests a promising path toward more adaptable robots that learn similarly to biological organisms.
