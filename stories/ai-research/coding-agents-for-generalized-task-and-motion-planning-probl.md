Coding agents can write generalizable planning programs for complex robotics tasks. Claude and Codex were tested on 28 simulated environments, evaluated across 98,000 episodes, and achieved 56-95% success compared to 47% for hand-engineered planners. This matters because agent-written solutions maintain performance as task complexity grows.
