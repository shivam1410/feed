Coding agents can control robots through native interfaces without custom engineering or specialized tools. Claude Opus 5 achieved 99.0 percent success on CaP-Bench and 87.0 percent on LIBERO-PRO using only standard ROS 2 terminal access. The agent spontaneously organized perception as file I/O and manipulation as code. This demonstrates that off-the-shelf language models already work as capable visuomotor policies without task-specific training or bespoke primitives.
