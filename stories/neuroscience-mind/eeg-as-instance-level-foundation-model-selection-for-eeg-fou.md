EEG-AS selects the best performing foundation model per individual brain-signal sample rather than using one model for all. It learns to estimate model behaviors using latent embeddings and neurophysiological features from an anchor model, then chooses from seven alternatives without executing all of them. Tests on seven public EEG benchmarks show this instance-level selection substantially narrows the gap to the oracle upper bound, enabling efficient adaptive deployment of multiple specialized EEG models.
