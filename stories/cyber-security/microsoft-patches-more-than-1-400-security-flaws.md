Microsoft fixed more than 1,400 security flaws in Windows and its other software this month. That is well above September's record of nearly 1,000. One flaw is a zero-day, already exploited in the wild. It is a security feature bypass in the Windows Shell, affecting Windows 10 and 11. At least 78 fixes are rated critical, and most of those allow code execution. A.NET Framework bypass was disclosed earlier, though Microsoft sees no sign of exploitation yet. Windows 10 receives updates until October 2027.
