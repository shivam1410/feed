A new world model called μ₀ predicts smooth trajectories for key interaction points using 3D traces, enabling robots to learn from visual demonstrations without requiring explicit action labels. This approach is embodiment-agnostic, meaning the same learned model can transfer across different robot morphologies. By leveraging 3D interaction traces as a common representation, the system scales effectively to complex manipulation tasks while reducing the annotation burden typically required for robot learning. The scalability and transfer capabilities make this particularly valuable for training diverse robotic platforms from a single model.
