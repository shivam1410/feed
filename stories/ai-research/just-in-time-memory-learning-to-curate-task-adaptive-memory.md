Just-in-Time Memory keeps raw agent experience instead of storing fixed summaries, then adapts retrieved memories to each new task at reading time. The approach improved agent success rates by 16.2, 16.3, and 3.9 points on three benchmarks compared to traditional memory systems. Task-specific memory helps agents learn more effectively from their past experiences.
