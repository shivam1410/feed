Researchers created WideSWE to test whether AI coding agents can coordinate changes across multiple software repositories. Testing seven agents on 120 real-world tasks across 103 software ecosystems yielded success rates from 10.83% to 42.50%. Agents struggled most with identifying necessary cross-repository changes, revealing why production software development exceeds single-codebase tasks.
