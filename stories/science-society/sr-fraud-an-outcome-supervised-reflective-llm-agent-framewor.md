SR-Fraud addresses real-time payment fraud in non-stationary environments where adversaries adapt before labels mature. It decouples immediate transaction scoring from offline learning: a frozen agent evaluates transactions while a reflection agent proposes updated fraud boundaries. On production benchmarks, SR-Fraud improves all detection metrics and detects emerging fraud bursts faster than baselines.
