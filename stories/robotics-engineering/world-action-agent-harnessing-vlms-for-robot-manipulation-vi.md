A multi-agent system lets vision-language models control robots by rehearsing actions before execution. On LIBERO-Pro, it reached 75.6% success, outperforming end-to-end vision-language-action models and code-as-policy agents. This matters because previewing actions in simulation lets robots catch and correct errors before real-world execution.
