Using 297,861 All of Us participants, researchers found that three-year trajectories of routine biomarkers predict functional decline 3–12 months before falls occur. Machine learning models using trajectory features (slope, variability, mean, delta) achieved AUROC 0.797 versus 0.755 for static snapshots. The prediction signal remained independent after controlling for age and sex. This matters because hospitals already collect these measurements; passive EHR integration could identify pre-clinical decline without new tests, enabling early intervention before mobility loss becomes irreversible.
