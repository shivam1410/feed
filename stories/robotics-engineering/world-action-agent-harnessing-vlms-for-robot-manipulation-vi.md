Researchers created World Action Agent, a system where vision-language models visually control robot arms using rehearsable action proposals. On the LIBERO-Pro benchmark, the agent achieved 75.6 percent success rate, outperforming other robot learning systems. This approach lets robots manipulate objects by reasoning visually without writing code.
