Real-world GUI agent demonstrates strong performance across mobile and desktop environments using unified action space. Qwen-UI-Agent achieves 82.1% on MobileWorld and competitive performance with Opus 4.8 and Gemini 3.1 Pro on desktop and web tasks. The system combines sandbox environments with real-device mobile runtime and uses online reinforcement learning on trajectories exceeding 100 turns. The approach shows GUI agents can handle long-horizon workflows combining graphical and command-line operations.
