If you run PHP 8.x, upgrade now. Today's release fixes two remote code execution holes across the whole line. Exploits were already circulating, because the coordinated disclosure leaked. Two CVE IDs appeared online with the wrong release time and an inflated CVSS score of 10.0, when the real score is 9.2. PHP moved its pre-announcement and release up a day. A security firm also mistakenly published a video showing a proof of concept, and copies spread. That helped speed up exploit development.
