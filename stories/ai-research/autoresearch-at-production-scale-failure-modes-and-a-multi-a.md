An LLM that autonomously rewrites training code ran 220 experiments over twelve weeks on production recommendation systems. It discovered five failure modes unique to production scale that don't show up in academia: fragile infrastructure, agent memory decay, search stagnation, uneven iteration costs, and obsessive metric chasing. The system delivered 1.82x recall lift and designed fallbacks that expanded coverage 5.8x.
