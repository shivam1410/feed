AIDE² implements recursive self-improvement, where an AI research agent autonomously rewrites its own code to improve performance. Over an 8-day run, the system discovered seven successive improvements including new search policies and memory mechanisms. These improvements generalized to four held-out benchmarks spanning machine learning, algorithms, and weather forecasting, with the discovered agent matching or exceeding human-engineered production systems. This addresses a long-standing economic problem: how to sustain returns on R&D spending as costs grow exponentially.
