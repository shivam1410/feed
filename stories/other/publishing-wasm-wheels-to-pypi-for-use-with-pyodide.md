Pyodide 314.0 enables Python package maintainers to publish packages for Pyodide directly to PyPI using the PyEmscripten platform. Previously, Pyodide team members maintained over 300 packages, creating bottlenecks. Now, maintainers publish Pyodide-compatible wheels using standard PyPI processes. Simon Willison celebrated by publishing luau-wasm, packaging the Luau programming language compiled to WebAssembly. This shift removes the primary obstacle to ecosystem growth, democratizing Pyodide package development and enabling community contributions at scale.
