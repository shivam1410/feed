MLEvolve is an LLM-based multi-agent framework that autonomously discovers novel machine learning algorithms through long-horizon exploratory search. The framework advances prior work through three key improvements: enhanced search mechanisms for efficiently exploring the algorithm design space, sophisticated memory systems for retaining previously discovered solutions and patterns, and adaptive coding strategies enabling agents to write higher-quality implementation code. Rather than relying on human-designed algorithms, the system discovers solutions optimized for specific problem structures. This represents significant progress toward fully automated machine learning algorithm discovery through AI-driven reasoning.
