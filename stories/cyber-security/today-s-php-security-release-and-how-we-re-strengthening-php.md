PHP shipped emergency fixes for two remote code execution holes across its whole 8.x line. Exploits were already circulating after a disclosure leak. CVE IDs appeared online on October 20 with a wrong release time and a CVSS score of 10.0, when the real score is 9.2. A security firm also posted a video of its proof of concept by mistake, which sped up exploit development. Why it matters: anyone running PHP 8.x needs to upgrade now.
