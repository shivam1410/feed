A developer built llm-typesafe, a plugin for the llm tool that adds support for TypeSafe AI's Jev model. Jev specializes in yes/no questions, choice categorization, and scoring tasks. Install it with llm install llm-typesafe, set your API key, then ask structured questions like "Does this message request a refund?" and get confidence scores. This brings specialized reasoning models to the command line.
