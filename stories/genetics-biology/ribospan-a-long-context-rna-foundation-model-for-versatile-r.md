RIBOSPAN is a bidirectional RNA foundation model pretrained on sequences up to 10,240 nucleotides, enabling high-resolution full-transcript modeling and strong long-context representations. The model supports discrete-diffusion-based mRNA generation and redesign. By processing longer RNA sequences holistically rather than fragmentarily, RIBOSPAN improves accuracy in identifying functional elements that span entire transcripts. This matters for both fundamental RNA biology and therapeutic applications where mRNA modifications require precise transcript-wide reasoning to maintain biological function while achieving desired sequence properties.
