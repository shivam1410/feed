This work deconstructs reinforcement learning post-training mechanics by isolating base model distribution, reward signal granularity, prompt diversity, and scale effects. Using policy output entropy as an analytical lens, researchers reveal how pretraining, supervised fine-tuning, and RL each shape model certainty. Key findings show spurious reward effects depend on prompt distribution and RL success depends on base models already assigning high probability to desired behaviors—connecting classical exploration constraints to modern LLM training.
