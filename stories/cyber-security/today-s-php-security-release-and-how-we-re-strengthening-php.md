PHP has shipped emergency fixes across the 8.x line for two remote code execution flaws. Exploits were already circulating because of a leak in the coordinated disclosure process. The CVE IDs appeared online on October 20 with a wrong release time and a CVSS score of 10.0. The real score is 9.2. PHP moved its pre-announcement and release up. Calif then mistakenly published a proof-of-concept video, and copies spread online. That sped up exploit development. If you run PHP, upgrade now.
