N₀-VTLA is a vision-tactile-language-action foundation model pretrained on NeoData, a large-scale visuo-tactile robot dataset. Using visuo-tactile pre-training, staged tactile integration, and ALTER offline reinforcement learning, it achieves 63.8% success on simulation tasks versus 44% for baselines and wins all nine NeoReal contact-rich manipulation benchmarks. Tactile perception enables fine motor control crucial for deformable objects.
