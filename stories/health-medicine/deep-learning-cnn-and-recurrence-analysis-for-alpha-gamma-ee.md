Fragile X Syndrome causes abnormal brain oscillations linked to cognitive impairment through disrupted synaptic plasticity and excessive network activity. This paper develops an automated deep learning system to detect FXS patterns in electroencephalography recordings. The hybrid framework integrates convolutional neural networks and LSTM recurrent networks, processing alpha (8–12 Hz) and gamma (30–100 Hz) oscillations through complementary representations: temporal feature sequences, time-frequency spectrograms, and recurrence plots encoding nonlinear dynamics. CNN modules extract spatial-spectral textures while LSTM layers model temporal modulation of oscillations. Subject-independent testing shows the hybrid model outperforms single-modality approaches, with gamma features providing strong discrimination power and alpha-gamma integration yielding further improvements. Automated detection could accelerate clinical diagnosis and research into FXS mechanisms.
