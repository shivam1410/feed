Visual-Seeker enables deep web search by treating visual reasoning as a primary capability rather than secondary to text. The system performs active visual reasoning—iteratively generating queries and interpreting visual results—to conduct comprehensive searches of real-world web content. It outperforms both open-source baselines and proprietary visual search systems on benchmark tasks. The visual-native approach allows the system to understand and act on visual information directly without translating to text first. This capability is particularly valuable for discovery tasks where text-only search misses crucial visual context or where images contain information unavailable in textual form.
