World Action Agent lets vision-language models pilot robots through a workspace where they preview actions before executing them and see and correct residual errors in the same visual view. On LIBERO-Pro, WAA hit 75.6 percent average success, beating end-to-end agents and code-as-policy baselines. This matters because previewing actions reduces wasted trial-and-error in robot learning.
