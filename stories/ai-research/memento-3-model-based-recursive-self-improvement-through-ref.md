Memento 3 is a frozen LLM that learns world models through a natural-language rulebook stored as persistent memory. The agent revises the rulebook based on prediction errors, then compiles it into code for planning. On ARC-AGI-3, it solved every level of all 25 games, showing that fixed models can improve through external memory.
