Researchers implemented an integer-only quantized transformer for jet tagging on AMD Versal AI Engines, directly addressing the challenge of deploying neural networks in extremely low-latency trigger systems at CERN's Large Hadron Collider. The framework automatically maps dense and multi-head attention layers to reconfigurable hardware tiles while generating corresponding Vitis graph code from high-level Python model descriptions without manual optimization. This reusable, open-source software framework provides a practical foundation for deploying transformer models at minimal latency in resource-constrained, real-time particle physics applications and triggers.
