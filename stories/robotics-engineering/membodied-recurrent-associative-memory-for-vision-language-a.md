Robot policies can use compact episodic memory with an associative state and scene reference instead of storing full history. On memory-dependent tasks, this achieved 7.8 times the success of stateless policies, using 10 times fewer parameters. This matters because fixed-size memory preserves task-relevant history without bloating the context window.
