World Action Agent lets vision-language models control robots through an editable visual workspace. Robots preview actions through action rehearsal and in-view correction before committing. The system learns embodied skills from videos and human teaching. On LIBERO-Pro, it achieved 75.6 percent success. Learned skills transferred to unseen simulated environments. This matters because VLMs can become robot brains with visual grounding and practice.
