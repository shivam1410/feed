Long-horizon robotic manipulation tasks require robots to reason about visual information over extended action sequences. EventVLA introduces a sparse visual evidence memory framework with dynamic Keyframe Evidence Memory module and visual anchors. This approach reduces memory overhead while maintaining task-relevant information and visual context across manipulation steps. Better long-term visual reasoning enables robots to perform complex multi-step manipulation tasks requiring sustained visual attention and recall of earlier observations.
