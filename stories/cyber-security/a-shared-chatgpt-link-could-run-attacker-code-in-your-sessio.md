Researchers at Parameter showed that a malicious ChatGPT share link could run an attacker's code in anyone's logged-in session. Opening the link could expose private conversations. They reported it through OpenAI's bug bounty on October 18. OpenAI fixed it eight days later and rated it P1, its most serious category. Why it matters: a single click could expose a user's private chats.
