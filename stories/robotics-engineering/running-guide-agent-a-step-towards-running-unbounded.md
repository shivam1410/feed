Running Guide agent is an AI assistant enabling blind and low-vision athletes to run independently. The system provides real-time audio navigation with directional cues and includes obstacle detection to alert users to hazards ahead. By removing dependence on sighted guides, the technology increases athletic independence for people with visual impairments. This addresses a significant barrier to competitive running participation and demonstrates AI's potential to enhance accessibility in sports.
