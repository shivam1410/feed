This model-agnostic framework analyzes per-modality failures in multimodal clinical AI, addressing a critical deployment gap: when some modalities become unavailable, which one caused accuracy loss and did the model fail detectably ('loudly') or unflagged ('silently')? The framework provides per-example failure taxonomy and per-modality complementarity matrices attributing errors to specific modalities using only deployment-observable signals. Validation against planted ground truth confirmed recovery of per-modality dominance and complementary modality subsets.
