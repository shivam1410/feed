SpatioTemporal Causal Network Diagnostics (ST-CND) provides early warning for geographic tipping points in ecosystems, climate subsystems, and ice sheets. Rather than global spatial indicators, the framework represents geographic fields as time-evolving directed causal networks, inferring which spatial nodes help predict others via transfer entropy and data-driven information flow. It estimates local recovery rates within candidate subnetworks using dynamic mode decomposition. Vulnerabilities are identified by combining three signals: high internal fluctuation, high internal synchronization, and low external coupling. On North Atlantic AMOC data, ST-CND achieved AUROC 0.783, substantially outperforming baseline methods.
