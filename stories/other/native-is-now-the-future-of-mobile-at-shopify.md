Shopify is switching from React Native back to separate Swift and Kotlin native codebases after six years. The original 2020 rationale for React Native—avoid building features twice and reduce feature-parity chasing—remains valid. However, AI coding agents now handle enough cross-platform implementation, testing, and review work that maintaining two codebases is no longer economically prohibitive. This signals a significant shift: AI has reduced the cost penalty of native development enough to make it competitive again. Shopify will transition or archive its React Native libraries.
