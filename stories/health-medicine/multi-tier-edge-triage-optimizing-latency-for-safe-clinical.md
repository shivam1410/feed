Clinical AI agents need safety checks, but cloud judges add delay. This system runs a small classifier on the host server. It clears clear queries in-process and escalates only ambiguous ones to a cloud LLM judge. Frozen local encoders match cloud models on PHI detection, at 98.3% accuracy or higher, and run 14x faster. Local recall hit 100% on PHI and brand violations. Reading-level checks were weaker, at 93.3% to 95.3%.
