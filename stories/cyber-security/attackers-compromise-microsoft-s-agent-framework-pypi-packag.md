Attackers compromised Microsoft's agent-framework package on PyPI. Versions 1.26.1 and 1.26.2 were published 33 minutes apart on November 17, 2026. The malicious versions run a credential stealer every time Python starts. Several security firms, including Wiz and Socket, reported the compromise.
