Mojo, a GPU-focused programming language, has been released as open source under the Apache 2 license. The compiler and toolchain release today follows the version 1.0 milestone shipped last week, fulfilling a promise made in May 2023. Originally designed as a Python superset to leverage existing code, the language pivoted strategy around August 2025 to prioritize GPU optimization with Python-inspired syntax. The developers report that AI-assisted coding tools effectively help migrate Python code to Mojo, and expect ecosystem maturity to ease transitions further. By opening the source code, the project removes adoption barriers and signals production readiness for GPU-accelerated computing, potentially lowering the barrier for developers to adopt GPU programming.
