SuperNav pairs a pretrained vision-language model with a specialized agent harness that includes Navigation Skills tools and a visual-point interface for specifying destinations in images. Without fine-tuning the model itself, it outperforms baselines on diverse tasks and demonstrates success on a real quadruped robot. This shows that general-purpose models plus good tools beat task-specific training.
