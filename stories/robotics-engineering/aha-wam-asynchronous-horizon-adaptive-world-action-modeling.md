AHA-WAM is an asynchronous world-action model using dual Diffusion Transformers for robotic manipulation tasks, enabling efficient long-horizon planning paired with real-time action execution through specialized pipelines. This design allows the system to plan ahead while executing current actions simultaneously. Combining predictive world models with actionable planning in an asynchronous, efficient framework advances robotic control capabilities toward handling more complex, extended-horizon manipulation tasks in dynamic environments.
