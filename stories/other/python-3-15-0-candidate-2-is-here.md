Python 3.15.0 release candidate 2 available, final release October 2026. RC phase restricts changes to bug fixes only. Release manager Hugo van Kemenade urges third-party projects to test immediately and publish wheels on PyPI. Binary wheels built against RC versions remain compatible with final release and future 3.15 versions. Testing RC versions matters: many developers skip this phase, letting bugs ship in stable releases. Van Kemenade demonstrates using GitHub Actions with allow-prereleases flag to automatically track RCs then transition to stable.
