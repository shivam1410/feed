ED-CSP is a machine-learning framework that predicts crystal structures from electron diffraction observations combined with chemical composition and atom count. The generative model jointly predicts lattice parameters and atomic coordinates using relational encoders, multi-view aggregation, and periodic flow generation. Trained on 4.85 million simulated structures, it achieved 57.49% match rate (MR@5) on held-out test structures, outperforming state-of-the-art powder X-ray diffraction methods (52.92%). Scaling training data improved performance to 66.27%; crucially, the model demonstrates true generative capability beyond structure retrieval on unseen compositions.
