Security researchers warned of an active campaign targeting Rust developers and crate maintainers. Attackers pose fake opportunities via video call, tricking targets into installing malware or running commands. Last month this succeeded against the array_ref crate, compromising the dependency chain. This matters because open source security depends on the weakest link in a thousand-person supply chain.
