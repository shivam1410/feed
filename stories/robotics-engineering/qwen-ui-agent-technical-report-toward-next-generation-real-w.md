Qwen-UI-Agent is a foundation GUI agent for real-world device control across mobile, desktop, web, and search interfaces, combining visual interaction with command-line execution. It achieved 82.1% on MobileWorld and 92.2% on mobile benchmarks, matching or exceeding frontier models including Opus 4.8 and Gemini 3.1 Pro. The agent uses diverse sandbox environments, real device runtime, and online reinforcement learning on trajectories exceeding 100 steps.
