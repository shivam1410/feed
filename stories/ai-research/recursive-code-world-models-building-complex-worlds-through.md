Recursive Code World Models builds complex 3D worlds as executable code from a single image by recursively alternating between global and local scene reconstruction. The system shares camera alignment constraints across reconstruction passes, enabling consistent geometric interpretation. Starting from one image, RCWM produces procedural code that generates increasingly detailed 3D scenes, treating world construction as a programming problem rather than merely a rendering task. This approach demonstrates how scene understanding can bridge vision and code generation, with implications for graphics, robotics, and simulation applications requiring detailed environmental models.
