Protein language model embeddings can be reshaped to predict function better. The method, SAVR, uses Pfam family membership as a homology-based signal in a contrastive post-training step. It spreads variance across embedding dimensions, so less of the signal sits in a few directions. With no task labels during post-training, it reaches state-of-the-art results on Enzyme Commission benchmarks and competitive results on Gene Ontology. All of this holds with the backbone frozen, which matters for predicting protein function from sequence alone.
