Meta released Muse Glimmer, a 30-billion-parameter open-weights model under Apache 2.0 license optimized for end-to-end agentic task completion and tool use. The model achieves strong performance on DeepSearch QA, MCP-Atlas, τ-Bench, and SWE-Bench—benchmarks measuring ability to work within scaffolds, write and debug code, and handle multi-turn requests from initiation to completion. Glimmer demonstrates reliable function calling with precise schemas across extended workflows and maintains coherent multi-step reasoning across complex tasks. An 18.16 GB version runs on machines with 32+ GB RAM, leaving substantial capacity for concurrent applications. The model represents a significant step in accessible open-weight agentic AI, enabling local deployment of reasoning and tool-use capabilities previously limited to proprietary cloud services.
