TacForcing is a streaming action-generation framework for robotic manipulation that integrates real-time tactile feedback during task execution. Using a streaming action expert and execution-aware tactile attention, the system improves performance on contact-rich manipulation tasks where traditional visual feedback alone is insufficient.
