The US government suspended Fable 5 access citing national security concerns about a jailbreak: asking the model to fix code containing known vulnerabilities. Researcher Kate Moussouris argues this classification is absurd—fixing bugs and writing security tests constitute core defensive work, not attack capability. Testing code with known CVEs and deliberately planted vulnerabilities, then generating fixes, represents essential security practice. The technique is not a guardrail bypass but standard industry methodology. Banning this removes fundamental defense tools from US cybersecurity operations.
