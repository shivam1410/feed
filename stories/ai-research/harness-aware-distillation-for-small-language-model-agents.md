Distillation method focuses on teaching small agents what the surrounding software cannot handle. Instead of imitating the full teacher output, it contrasts the teacher's decisions with and without harness information, using no task rewards or labels. This matters because deployed agents work inside software scaffolds that handle much of the work, so students should learn only the gaps.
