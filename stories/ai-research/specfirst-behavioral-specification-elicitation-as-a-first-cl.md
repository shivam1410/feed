Building complete programs from scratch defeats most language model agents—frontier models solve fewer than 1% of ProgramBench tasks despite documentation and binary oracles. SpecFirst applies classical requirements engineering: dedicated specification agent probes binary, combines observations with documentation, synthesizes structured specification; code synthesis agent then implements from stable behavioral reference. Decomposition resolves documentation ambiguities before coding, preventing early misinterpretations from cascading into implementation. Evaluation across 200 ProgramBench instances and four model families shows consistent improvement: test pass rates increase 6.9%–21.3% over single-loop baselines, substantial gain on this difficult task.
