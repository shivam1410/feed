MRAgent proposes that memory in large language models works through active reconstruction rather than simple retrieval, combining associative memory graphs with dynamic access during reasoning. This approach improves long-horizon memory reasoning—critical for maintaining coherent context over multiple steps—while simultaneously reducing computational costs compared to full-retrieval methods. The mechanism uses graph structures to organize memories and reconstruct relevant information on-demand rather than storing complete traces. This is significant for practical LLM deployment, offering both improved reasoning capabilities and efficiency gains, addressing key constraints in scaling language models.
