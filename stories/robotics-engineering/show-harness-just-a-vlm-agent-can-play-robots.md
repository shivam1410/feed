Show-Harness bridges vision-language models to robot control by interpreting VLM outputs as discrete semantic actions (e.g., grasp, move left) that embodiment-specific modules then translate into low-level robot commands. This architecture enables both zero-shot deployment—VLMs guide robots they've never seen—and efficient fine-tuning when needed. The method works across different robots and GUI interactions, reducing the need to retrain for new hardware. This is significant because it makes VLMs practical for robotics without requiring task-specific training data or robot-specific model variants.
