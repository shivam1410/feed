Attackers used autonomous AI agents to find a new flaw in MONAI Label, an open-source medical imaging server. Amazon Threat Intelligence reported that suspected China-linked hackers did this. The bug lets an attacker with no account write files outside the server's storage folder. The attackers used it to gain root access on a university server. Versions 0.8.5 and earlier are affected in the default setup.
