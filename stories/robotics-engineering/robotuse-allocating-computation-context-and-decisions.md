Robot agents learn by revising actions through repeated attempts. RobotUse organizes agent decisions around visual targeting and pose selection, with motion planning handled by the backend. On RoboLab, it achieved 45 percent task success while outperforming the closest baseline by 6.7 percentage points. The system transfers learning across tasks even when real-world feedback is imperfect, building persistent playbooks from experience.
