Single-cell transcriptomics of fruit fly nerve cords mapped to circuit wiring uncovered a shared gene-expression code that acts as a molecular timestamp. This code preserves each neuron's birth order from its parent cell, functioning as an internal clock that encodes developmental history. This 'birth-order code' shapes neuronal identity and contributes to neural diversity. Understanding this mechanism reveals how temporal information during development programs cell type diversity across nervous systems.
