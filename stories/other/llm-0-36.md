Version 0.36 of the llm command-line tool added support for GPT-6 Sol and Luna models. It also introduced a flag for single-turn models that can't maintain conversation history, letting the tool reject inappropriate inputs before errors occur. It's a small infrastructure update but necessary plumbing to support new model types that don't follow traditional chat patterns.
