ASPIRE is a continual learning system enabling robots to autonomously develop and refine control programs through iterative exploration and skill discovery. The system demonstrates superior performance on manipulation and household tasks while achieving zero-shot generalization to novel scenarios without explicit retraining. Notably, ASPIRE enables successful sim-to-real transfer, where skills learned in simulation function effectively on physical robots. By automating discovery of new control strategies through exploration, the system reduces dependence on manual programming or human demonstrations. This autonomous capability to progressively build more capable control policies positions ASPIRE as a practical framework for developing generalizable robotic skills across diverse task domains.
