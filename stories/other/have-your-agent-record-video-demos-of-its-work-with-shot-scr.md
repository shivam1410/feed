shot-scraper version 1.10 introduces a new video-recording command that automates demo creation for web applications. Users define interaction workflows in a storyboard.yml file specifying server setup, viewport dimensions, and sequences of user interactions, which Playwright then automatically records as video. The example demonstrates recording a Datasette feature for bulk-inserting data from CSV, TSV, or JSON files into database tables. This tool enables AI coding agents to automatically produce video evidence of their work, facilitating easier validation and comprehensive documentation of agent-generated functionality changes and feature implementations.
