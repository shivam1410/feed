Researchers showed coding agents can solve complex long-horizon robotic tasks and transfer solutions across different robots. They created EMBODIEDSWE-GEN to convert each solution into diverse training data for robot policies. A Vision Language Agent trained solely on AI-generated demonstrations then completed a long-horizon task on real hardware. This shows how AI planning bootstraps physical robot learning.
