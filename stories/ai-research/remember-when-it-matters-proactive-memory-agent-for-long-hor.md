Long-horizon AI agents fail through behavioral state decay when decision-relevant information gets buried in expanding trajectories. A separate memory agent runs alongside action agents, updating a structured memory bank and selectively injecting reminders. Improvements reach +8.3 and +6.8 percentage points on Terminal-Bench 2.0 and τ²-Bench. Selective intervention outperforms passive exposure and always-on injection. Researchers trained Qwen3.5-27B using SFT and GRPO with partial transfer success.
