T1 is a 122-billion-parameter Mixture-of-Experts language model trained with reinforcement learning to execute complex, long-horizon terminal (bash/shell) tasks in isolated cloud sandbox environments. The model employs stable actor-critic optimization to learn effective sequences of commands spanning multiple steps, and out-of-distribution training to handle unexpected execution contexts. It achieves state-of-the-art performance on long-horizon task execution benchmarks. This work demonstrates how model scale combined with specialized RL training can enable AI systems to autonomously handle sustained sequences of terminal operations, maintaining reasoning and context over extended execution horizons.
