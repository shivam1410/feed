Engineers built PyRUA-Lean, a framework for robot control that composes classical primitives with vision-language policies into code that selectively requests observations. The framework increased success rates from 63.1 percent to 71.7 percent while using 49 percent fewer LLM calls and 65 percent fewer tokens. Robots become more efficient when agents ask for feedback strategically instead of at every step.
