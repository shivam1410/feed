Most AI agents solve narrow tasks but forget knowledge across different domains. OPD-Evolver combines slow-fast co-evolution—where a fast-learning policy learns quickly while a slower base policy provides stability—with on-policy self-distillation where the agent learns from its own experience. The framework enables agents to enhance memory management and policy learning simultaneously across multiple domains. By evolving alongside task-specific improvements, the agent continuously improves its learning mechanisms rather than using fixed strategies. Early results show this self-evolving approach maintains or improves performance across diverse tasks, suggesting agents can be designed to improve their own learning over time.
