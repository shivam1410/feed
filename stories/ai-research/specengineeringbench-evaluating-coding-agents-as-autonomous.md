Coding agents can write tests that look good, but that does not mean they find bugs. A new benchmark gave seven frontier agents 100 tasks from 78 Python repos. They scored 91.47% on head pass rate and 80.48% on change-focused coverage. Their fail-to-pass rate was only 26.36%. Pinpointing bad code also got harder, with recall falling from 78.11% at file level to 51.29% at function level. Coverage alone does not show that defects are caught.
