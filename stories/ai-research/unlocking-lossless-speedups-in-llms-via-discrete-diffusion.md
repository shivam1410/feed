A new method accelerates LLM inference by combining autoregressive generation with parallel token sampling via diffusion models. The approach uses distilled diffusion weights and a specialized sampler, achieving speedups without sacrificing output quality or requiring traditional draft models. This lossless speedup is valuable because inference latency and cost are major barriers to LLM deployment. The technique could make real-time applications more feasible and reduce computational overhead.
