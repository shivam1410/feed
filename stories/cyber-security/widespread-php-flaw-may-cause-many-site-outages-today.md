Nearly 70 percent of websites need to update core software after a pair of critical PHP flaws. The bugs let attackers run code of their choosing on a server. Experts say working exploits exist and are already being used in the wild. Reuters reports government sites in Europe went offline. Cloudflare said it saw some exploitation and added firewall rules at 3:02 UTC. OpenAI, which helped with the research, called it one of the most impactful security issues in recent memory.
