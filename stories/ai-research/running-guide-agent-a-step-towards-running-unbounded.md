Running Guide is an AI agent that provides real-time audio navigation and obstacle detection, enabling blind and low-vision (BLV) athletes to run independently without sighted guides. The agent perceives the environment and delivers audio cues in real time, removing a major barrier to independent athletic participation. This addresses a significant accessibility gap: BLV individuals have limited options for independent aerobic exercise, and existing solutions require constant human assistance.
