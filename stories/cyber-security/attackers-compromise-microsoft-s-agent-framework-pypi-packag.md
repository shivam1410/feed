Attackers compromised Microsoft's agent-framework package on PyPI, the Python package site, and pushed a credential stealer. The bad versions, 1.26.1 and 1.26.2, were published 33 minutes apart on November 17, 2026. The stealer was built to run on every Python start. Eight security firms reported it, including Wiz and Socket. Why it matters: anyone who installed those versions could have lost cloud credentials.
