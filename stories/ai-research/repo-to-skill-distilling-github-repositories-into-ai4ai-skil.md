DisCo, a research agent, distills operational knowledge from GitHub repositories and transforms it into reusable artificial intelligence skills. This systematic knowledge extraction significantly improves autonomous machine learning research performance across multiple benchmarks. The approach addresses a key challenge in AI research: capturing and reusing insights from existing work efficiently. By converting repository knowledge into reusable skills, the method accelerates research cycles and enables researchers to build on prior work more effectively.
