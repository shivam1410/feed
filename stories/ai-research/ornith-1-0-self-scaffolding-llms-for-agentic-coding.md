DeepReinforce released Ornith-1.0, an open-source MIT-licensed model family for agentic coding with variants from 9B to 397B parameters. Built on Gemma 4 and Qwen 3.5, it achieves state-of-the-art coding performance among comparable open-source models. Early testing shows efficient agent harness execution at 103 tokens per second, handling complex code search tasks with ease. This accessible alternative to proprietary models democratizes AI-assisted development, providing builders with capable tools without vendor lock-in or restrictive licensing for commercial applications.
