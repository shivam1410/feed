VIABench is a video benchmark testing multimodal large language models on real assistance scenarios for visually impaired individuals using first-person videos recorded by VIIs themselves. It defines three distinct tasks: Proactive Reminder (anticipating and describing upcoming navigation-critical events), Visual Question Answering (answering user questions about environment or objects), and Vision-Guided Interaction (context-aware reasoning for intentional interactions). The evaluation supports both online (real-time) and offline settings for robust assessment. Experiments show current MLLMs still struggle significantly with comprehensive support, particularly on the Proactive Reminder task, which demands accurate anticipation and real-time responsiveness. This matters because it identifies gaps between impressive general vision-language performance and practical utility in accessibility applications where VIIs depend on accurate, timely information.
