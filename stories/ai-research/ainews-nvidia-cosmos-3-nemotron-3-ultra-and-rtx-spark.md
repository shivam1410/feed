NVIDIA released Cosmos 3, an open-source family of world models that can process language, images, video, audio, and actions in a unified architecture. The system uses a Mixture-of-Transformers design pairing an autoregressive reasoner with a diffusion generator. The base Nano model has 16 billion parameters split between reasoning and generation towers, while the larger Super model has 64 billion. NVIDIA released optimized versions for text-to-image and image-to-video that now rank as state-of-the-art open-weight models. Alongside this, NVIDIA announced Nemotron 3 Ultra, an efficiently-designed 550-billion-parameter language model, and previewed the RTX Spark personal supercomputer.
