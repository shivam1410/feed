Anthropic has introduced dynamic workflows, which its presenters call flows. They describe flows as a new type of multiagent orchestration for big, ambitious work. Their core argument is that agents need the same structure that large open source projects use, from early Unix to Linux's trusted maintainers. The text has few technical details.
