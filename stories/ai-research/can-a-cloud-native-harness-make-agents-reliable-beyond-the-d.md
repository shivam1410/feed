Two Kubernetes creators want to run coding agents the way Kubernetes runs apps. Their company, Stacklok, is betting on it. Many coding agents started as local terminal tools, and moving them to the cloud is hard. The main challenges are keeping sessions reliable, isolating tool execution, and preserving context. Kubernetes uses control loops to keep apps running, recover from failures, and scale. Stacklok started in software supply chain security, then recently pivoted to Kubernetes-based agent tools. It raised a $17.5 million Series A in 2023. Why it matters: managing agents like cloud apps could make them more reliable.
