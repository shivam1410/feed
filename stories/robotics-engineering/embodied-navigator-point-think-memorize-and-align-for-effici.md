Embodied-Navigator (TAMP-Nav) improves navigation for embodied AI systems through three innovations: aligning vision-language models with 2D visual prompting for better environmental interpretation, selective reasoning with compressed memory for efficient computation, and dense policy optimization for refined behavior. These techniques address core navigation challenges: visual understanding, efficient reasoning with limited resources, and reliable action selection. By combining vision-language alignment with memory-efficient reasoning, the system advances robot navigation in complex real-world environments.
