IterSynth splits agent jobs into a Planner identifying information needs and a Synthesizer integrating evidence, then trains both using role-specific credit assignment. On five benchmarks like BrowseComp, IterSynth-8B scored 50.7, beating the prior best 8B agent by 4.2 points and working as a zero-shot prompting paradigm with GPT-4-class models. This matters because separating roles reduces the noise and confusion in long agent searches.
