LLM 0.32rc2 updates default model from GPT-4o mini ($0.15/$0.60 per million tokens input/output) to GPT-5.6 Luna ($0.20/$1.20), with fallback option for GPT-5 nano ($0.05/$0.40). New llm openai endpoint command enables running prompts, chats, and model listings against arbitrary OpenAI-compatible endpoints without logging or prior configuration. Users can switch defaults or test local models via uvx one-liner, reducing friction for evaluating models across providers and deployments.
