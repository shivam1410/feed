HIDE is a benchmark testing whether robot policies remember task history when visual observations alone aren't enough for reliable execution. It covers 15 tasks spanning repetition counting, historical state recall, and execution progress tracking. Many current robots fail badly on this. The SEEK memory framework helps by combining three complementary memory mechanisms, though individual mechanisms can hurt some tasks.
