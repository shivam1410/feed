LiveAnimate achieves real-time streaming of long-form, pose-driven human animation using a 14 billion-parameter video diffusion transformer. The system uses bounded attention caching and sequence parallelism to handle continuous generation without memory overflow. This enables real-time animation synthesis from pose control signals.
