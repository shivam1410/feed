Memory can hold up in old age when a certain brain enzyme is active. Data from mouse brains and 13 human brains show a link between the enzyme's levels and cognitive resilience. The findings show a link, not proof that the enzyme causes better memory. It matters because it points to a biological factor tied to memory in later life.
