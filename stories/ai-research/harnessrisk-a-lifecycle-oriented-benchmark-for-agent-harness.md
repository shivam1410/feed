HarnessRisk evaluates agent harness security across six operational phases, revealing configuration vulnerabilities and detection gaps allow high attack success despite preserved core functionality. This finding is critical: attackers can compromise agent harnesses while the underlying AI model operates correctly. Security often deteriorates across the operational lifecycle. The research highlights that securing AI agents requires addressing the entire execution environment, not just the model. Organizations deploying agent systems must strengthen configuration security and detection capabilities to prevent exploitation.
