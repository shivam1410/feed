Researchers developed UniSkill, a method where language model agents learn to propose and refine reusable skills as they solve tasks. The agent receives feedback based on how proposed skills would change its performance on previous successful and failed trajectories, avoiding costly new test runs. UniSkill reached 98.4% success on ALFWorld and 84.7% on WebShop while maintaining stable joint training of the policy and skill library. This matters because it shows LLM agents can continuously improve by distilling and reusing learned skills, offering a path toward more capable autonomous systems.
