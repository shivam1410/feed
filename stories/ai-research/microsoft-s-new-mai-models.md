Microsoft announced MAI-Thinking-1 (1 trillion total parameters with 35 billion active) and MAI-Code-1-Flash (137 billion total, 5 billion active). Both models were trained from scratch using enterprise-grade, clean, commercially licensed data without relying on third-party model distillation. The Code-1-Flash variant rolls out to GitHub Copilot users in Visual Studio Code. Microsoft's emphasis on appropriately licensed training data suggests a departure from models trained on unlicensed web dumps, though specific sourcing remains unclear.
