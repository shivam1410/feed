AffordanceVLA improves robotic manipulation by reasoning about object affordances. This vision-language-action model uses structured affordance forecasting as an intermediate representation to improve perception-action mapping in manipulation tasks. Better understanding of how objects can be acted upon enables more precise and reliable robotic control.
