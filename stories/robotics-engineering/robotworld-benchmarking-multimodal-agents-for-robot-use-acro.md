RobotWorld tests 84 robot tasks across manipulation, mobile control, driving, and aerial drones to see where AI agents succeed and fail. Astra excels at spatial and constrained-contact tasks while Opus 5.5 does better on continuous balance, showing different strengths. The main failures: agents forget object states mid-task, correct actions too late, or stop before finishing, revealing gaps in maintaining task context and recovery.
