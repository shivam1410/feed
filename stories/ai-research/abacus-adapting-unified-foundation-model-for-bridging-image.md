ABACUS is a unified vision-language model that performs object counting and related tasks through three complementary innovations: spatial grounding to pinpoint object locations, boundary-aware counting policies to handle challenging edge cases, and self-critical learning strategies to iteratively refine predictions. This integrated approach improves counting accuracy. Reliable object counting is fundamental to robotics, autonomous systems, and accessibility applications that depend on accurate visual understanding.
