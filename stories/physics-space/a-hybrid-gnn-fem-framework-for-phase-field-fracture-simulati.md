Phase-field fracture modeling requires solving coupled, nonlinear, history-dependent systems within finite element procedures—computationally expensive despite robustness. This hybrid framework integrates a graph neural network surrogate into the conventional staggered scheme, replacing the phase-field update at each load increment while retaining the FEM-based displacement solver. By preserving incremental solution structure and history-dependent evolution, the surrogate learns a physically meaningful target rather than approximating the entire trajectory. This selective approach maintains consistency with physical principles while leveraging machine learning's computational efficiency.
