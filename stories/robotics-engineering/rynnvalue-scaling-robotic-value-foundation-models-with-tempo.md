RynnValue is an open-source value foundation model for robotic manipulation that learns value predictions using temporal distance instead of human preferences or task progress signals. The model generalizes effectively across diverse manipulation tasks and improves real-world robot policy success rates. Temporal distance-based learning provides more stable and generalizable training signals compared to preference-based approaches. This methodology advances robotic learning by providing more reliable learning signals for training autonomous robot manipulation policies.
