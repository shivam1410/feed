Code-as-Policy treats the robot and environment as an Embodied Turing Machine where state and decisions live entirely in code, with no VLM or vision model in the loop at test time. On 42 bimanual tasks, the approach reached 70% success rate. Code makes decisions controllable, reusable, and fast.
