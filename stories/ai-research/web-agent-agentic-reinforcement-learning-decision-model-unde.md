A constrained reinforcement learning model for web agents tries to balance success, cost, and risk. Success-only strategies often end up with 'high success but high cost' or 'low risk but conservative failure.' The method tracks request count, latency, and failure penalties as costs, enforces budgets with Lagrange dual updates, and uses a CVaR term to avoid risky high-failure paths. Tests covered 800 to 1,500 end-to-end web tasks across 30 to 70 site templates. It matters because real web agents face budgets and delays, not just success rates.
