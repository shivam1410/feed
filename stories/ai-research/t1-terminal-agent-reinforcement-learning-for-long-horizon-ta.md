T1 is a 122-billion-parameter Mixture-of-Experts model trained with reinforcement learning to execute long-horizon terminal tasks in a cloud sandbox environment. The system uses stable actor-critic optimization and trains on out-of-distribution tasks to improve generalization. It can autonomously plan and execute multi-step sequences in cloud computing environments. This matters because automating complex cloud tasks—deployment, debugging, infrastructure management—could substantially reduce operational overhead and human error.
