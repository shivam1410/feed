Researchers built RoboArchitect, a system that designs the control code wrapped around a robot. It revises that code over many rounds while keeping the underlying policy frozen. No model weights get updated along the way. Success rose substantially on scenes and tasks the system had not seen. It also uses persistent memory. That matters because robots can improve without retraining the model.
