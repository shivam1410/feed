A system learns which roles and tools work best for each task, predicting the right agent harness without trial and error. SHIFT uses Monte Carlo search with learned value predictions across 9,193 tasks in six benchmarks, reaching 80 percent mean accuracy and beating 17 baselines by 7.2 percentage points. Choosing structure, instructions, and tools jointly beat fixing any one of them.
