A new llm-typesafe plugin integrates Jev into the llm command-line tool for developers building classification systems. You can ask yes/no questions, pose custom classification criteria, or request scoring across structured options, and receive confidence-scored JSON responses. It bridges the decision-model category into existing developer workflows, letting you compose state objects with queries and get back calibrated probabilistic judgments instead of hallucinating text.
