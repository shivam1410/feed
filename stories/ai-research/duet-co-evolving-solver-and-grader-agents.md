A solver and grader agent improve each other within a co-evolution loop. DUET iteratively executes tasks, evaluates outcomes, and updates both agents using a tool-using update module. Because grading becomes part of the optimization objective, the evaluator adapts as the solver improves, replacing a fixed evaluation bottleneck that would otherwise limit progress. Both agents improve together across four distinct benchmarks, consistently outperforming baseline approaches.
