BridgeVLA++ extends the BridgeVLA vision-language-action framework by equipping it with unified spatio-temporal memory architecture for robot 3D manipulation. The system models persistent spatial context and temporal interaction history, preserving data efficiency and generalization capabilities while adding memory-dependent reasoning. Achieves state-of-the-art performance on memory-dependent manipulation benchmarks and demonstrates effectiveness in bimanual manipulation. This approach enables robots to reason over observation histories while maintaining ability to learn from limited data—critical for real-world deployment where data is scarce and multi-step reasoning over past interactions is essential.
