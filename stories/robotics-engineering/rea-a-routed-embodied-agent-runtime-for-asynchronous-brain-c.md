A team built REA, a robot runtime that combines deliberate planning and quick reactions in one system. The two layers run asynchronously, so neither blocks the other. Tests covered both simulated and real robot tasks, with high success rates and lower control overhead. Robots need to plan ahead and still react fast when the world shifts under them, so this matters.
