XGBoost classifier achieved 0.982 macro AUC on held-out test set (n=247) for three-class Alzheimer's detection (normal cognition, mild cognitive impairment, Alzheimer's disease) using eight routine clinical biomarkers from ADNI dataset including MMSE, CDR scores, MoCA, and FAQ. SHAP explainability analysis revealed CDR Global dominates discrimination between normal and mild impairment, while CDR-SB and MMSE together drive Alzheimer's classification. Model accuracy reached 0.943 on test set with Cohen's kappa of 0.909. This near-perfect interpretable detection from standard clinical assessments accelerates diagnosis and provides clinicians actionable biomarker insights.
