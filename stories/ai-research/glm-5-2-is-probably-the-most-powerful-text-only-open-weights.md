Chinese lab Z.ai released GLM-5.2, a 753B-parameter text-only model with 1 million token context window, under MIT open license. It ranks first on Artificial Analysis Intelligence Index (score 51 versus competitors' 43–44 range) and second on Code Arena WebDev leaderboard, behind only Claude Fable 5. However, the model exhibits higher computational cost: producing 43k tokens per task versus competitors' 24–37k range. This efficiency trade-off between benchmark performance and token economy represents a practical constraint for real-world deployment at scale.
