Skill2Real lets robots learn manipulation tasks in simulation and apply them to real robots without retraining. A Cerebellum learns basic manipulation skills while a Brain learns task composition; both transfer frozen to real hardware via a shared API. Skills learned on simulated tasks achieved 78.75% success on four real-world manipulation tasks. This bridges the simulation-to-reality gap that normally blocks robot learning by grounding all skills in observable actions.
