SimpleICL clarifies what robot in-context learning actually is, then builds a minimalist framework with a visual prompt encoder that learns tasks from demonstrations. Without massive pretraining or specialized data infrastructure, the framework achieves strong performance in simulation and real-world robot environments. This makes learning from visual demos practical and reproducible.
