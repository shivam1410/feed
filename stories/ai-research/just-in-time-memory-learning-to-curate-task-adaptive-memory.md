Just-in-Time Memory keeps raw past trajectories instead of summarizing them at storage time, then synthesizes compact task-adaptive summaries at retrieval when the new task is known. On three benchmarks, JitMem improved over the strongest baseline by 16.2, 16.3, and 3.9 percentage points. This matters because deferring memory curation until you know what you need lets agents reuse experience more flexibly.
