Alaya-EVOKE introduces an interactive world model using external persistent memory and a redesigned long-horizon teacher to enable open-ended video generation. The system maintains bounded context and low latency while supporting responsive, extended video synthesis without linear computational scaling. This architecture enables long-horizon generation capabilities that were previously limited by context window constraints, advancing capabilities for open-world interactive video synthesis.
