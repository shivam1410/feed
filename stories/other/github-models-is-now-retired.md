GitHub has permanently retired GitHub Models, its unified API playground aggregating multiple LLM providers. The service was valuable because GitHub Actions could authenticate using ambient GitHub credentials, enabling easy LLM-powered automation. The company didn't explain the shutdown, but rising costs from coding agents using subsidized tokens likely drove it. Users must now migrate to alternative providers—the article's author switched to OpenAI with a monthly spending cap, running summaries through GPT-5.6 Luna. This shift from free, GitHub-provided access to self-managed API keys marks a significant cost change for developers relying on programmatic LLM access.
