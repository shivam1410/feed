Researchers demonstrated that cosmic protons in the Van Allen radiation belts create detectable neutron signals through spallation, observable using widely available sensor technologies. These neutron signatures can identify thermonuclear weapons aboard space satellites. The method provides a practical verification approach for arms control treaties using standard detection equipment.
