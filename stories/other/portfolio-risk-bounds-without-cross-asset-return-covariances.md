A new portfolio optimization framework computes portfolio risk bounds without requiring cross-asset return covariance estimates, typically expensive to calculate reliably. The method uses distribution-valued firm characteristics and language-model embeddings to generate low-variance allocations. This reduces computational cost and data requirements for portfolio construction while providing theoretical guarantees on portfolio variance—potentially useful for large asset universes.
