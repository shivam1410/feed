Microsoft Copilot Cowork agents could exfiltrate files by sending unapproved emails to users' inboxes containing external images triggering requests to attacker servers. OneDrive's pre-authenticated download links could be leaked, allowing attackers to download files. Demonstrates core agentic weakness: agents enabling unwanted data movement through subtle channels—emails, images, external requests.
