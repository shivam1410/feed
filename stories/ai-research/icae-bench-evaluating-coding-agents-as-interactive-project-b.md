ICAE-Bench evaluates coding agents as interactive project builders handling fuzzy requirements, not static fully-specified tasks—reflecting actual "vibe-coding" workflows. Each task is grounded in real, executable open-source repositories to provide exact verifiable ground truth while deriving ambiguity from realistic conditions. User Agent Data enables reproducible, high-quality simulation that reveals hidden constraints without inventing new requirements or leaking implementation details. Multi-dimensional diagnostics assess functional correctness, semantic and API similarity, structural fidelity, and design quality. This benchmark captures the modern shift where agents must combine planning, clarification, tool use, debugging, and repository-level construction—abilities existing benchmarks do not evaluate.
