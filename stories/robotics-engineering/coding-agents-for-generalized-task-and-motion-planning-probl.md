Coding agents like Claude Opus synthesize programs that generalize across task-and-motion planning problem instances. Tested on 28 simulated robotic environments, they achieved 56 to 95 percent success versus 47 percent for hand-engineered planners. The agents outperformed one-shot generation. This matters because LLMs beat specialized planning algorithms at generalization without domain-specific engineering.
