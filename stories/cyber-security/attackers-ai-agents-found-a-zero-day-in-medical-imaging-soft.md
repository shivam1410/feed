Amazon Threat Intelligence says suspected China-linked hackers used autonomous AI agents to find a new flaw. The flaw is in MONAI Label, an open-source medical imaging server. An attacker with no account could write files outside the server's storage folder. That led to root access on a university server. Versions 0.8.5 and earlier are affected in the default setup. It matters because AI agents found and used the flaw in a real system.
