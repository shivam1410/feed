A new agent design separates planning (finding what to search) from synthesis (integrating evidence) to reduce noise in long searches. IterSynth-8B scores 50.7 on benchmarks like BrowseComp, beating prior 8B agents by 4.2 percentage points. This matters because cleaner role separation helps agents handle long-horizon tasks without context pollution.
