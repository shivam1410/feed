Z.ai released GLM-5.2—753B parameter open weights model under MIT license—on June 16th. Features 1M-token context window, up from GLM-5.1's 200k. Ranks 1st on Artificial Analysis Intelligence Index (score 51, beating competitors at 43-44) and 2nd on Code Arena WebDev leaderboard behind Claude Fable 5, measuring agentic front-end development. Trade-off: GLM-5.2 generates 43k output tokens per task versus competitors' 24-37k, requiring higher inference costs despite capability advantages.
