Researchers tested household robot planners using the RobotValues benchmark, which presents scenarios where human values conflict. The study found that vision-language models controlling these robots have built-in value preferences they struggle to override when given instructions to prioritize different values. This matters because autonomous household robots will eventually make decisions affecting human welfare, and if they cannot properly incorporate diverse human values or switch between them when instructed, they could make poor choices that do not reflect what users want. The benchmark reveals a fundamental gap in how current AI systems handle competing human priorities.
