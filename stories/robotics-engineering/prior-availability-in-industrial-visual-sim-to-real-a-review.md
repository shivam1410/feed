Industrial robots must transfer skills from computer simulation to real physical environments, facing domain gaps when simulation doesn't perfectly match reality. Researchers reframe this sim-to-real problem by categorizing it according to prior availability — whether computer-aided design (CAD) models exist. Three settings emerge: CAD-available (models available), CAD-unavailable (no prior models), and boundary-prior (mixed availability). This taxonomy clarifies which techniques apply to different industrial deployment scenarios, enabling more robust robotics systems across manufacturing contexts with varying design documentation.
