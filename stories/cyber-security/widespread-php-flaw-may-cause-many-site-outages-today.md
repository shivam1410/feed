Two critical PHP bugs let attackers run code of their choosing on vulnerable servers, and they are already being exploited. PHP shipped an emergency fix. Nearly 70 percent of websites need to update their core software, since PHP powers Drupal, Magento, Joomla and WordPress. Cloudflare said it saw some exploitation and added firewall rules at 3:02 am UTC. Reuters reported that European government sites went offline. OpenAI, which helped with the research, called it one of the most impactful security issues in recent memory.
