TGO-IV introduces a topological framework using Persistent Homology to analyze how transformer representations evolve and transform across network layers. The method constructs Vietoris-Rips simplicial complexes from token-level representation point clouds and systematically tracks persistent topological signatures. This framework reveals how transformers progressively transform raw input representations into task-relevant feature representations. The topological lens provides new insights into transformer learning mechanisms and how feature formation emerges across network depth.
