This study tests whether shorter, less costly surveys can accurately measure poverty and inequality in low-income countries using machine learning. Analysis of Nigeria's 2018/19 household survey showed that poverty classification reached 90% accuracy using only five income predictors, and consumption-based poverty prediction achieved high accuracy with minimal expenditure categories. The findings suggest machine learning can help countries monitor welfare with simpler, cheaper surveys.
