Coding agents that work reliably on the desktop face challenges when scaled to the cloud, particularly keeping sessions reliable, isolating tools, and preserving context. Two Kubernetes creators are building cloud-native agent systems that use control loops similar to Kubernetes to keep applications running, recover from failures, and scale. This approach mirrors successful patterns from container orchestration.
