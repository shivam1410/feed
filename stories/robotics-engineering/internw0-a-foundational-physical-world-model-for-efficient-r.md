This physical world model predicts visual dynamics and robot actions at different speeds: slower processing for long-horizon context, faster for real-time responses. Trained on 7,200 hours of robot and egocentric video, it handles real tasks like chemical synthesis and precise pipetting. It reuses predictions rather than regenerating them. This matters because useful predictions must stay actionable as the world keeps changing.
