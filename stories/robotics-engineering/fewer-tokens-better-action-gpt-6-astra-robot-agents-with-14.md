Researchers built PyRUA-Lean, an interactive framework that controls robots using vision feedback and fewer tokens. Instead of repeatedly calling a language model, it composes robot primitives and learned policies into Python cells that perform conditional checks and retries, requesting only explicitly needed images. The system achieved 71.7% success versus 63.1% baseline while using 65% fewer input tokens on benchmark tasks.
