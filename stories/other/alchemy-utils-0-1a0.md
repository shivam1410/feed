Simon Willison released alchemy-utils 0.1a0, a database-agnostic Python library replicating sqlite-utils' API using SQLAlchemy for multiple database backends. Built using test-driven development with AI assistance, it supports PostgreSQL, SQLite, and DuckDB with both command-line and Python interfaces. The library demonstrates rapid AI-assisted development of working database tools. This matters because it brings powerful database manipulation tools to users of multiple database systems.
