Broadcom disclosed a critical VMware vCenter zero-day. An attacker with network access can bypass authentication and get unauthorized access. Fixed versions are out for all supported branches. There is no workaround, so patching is the only fix. vCenter is the central console for an organization's ESX hosts and virtual machines.
