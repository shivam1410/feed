Google reports that attackers have moved past manual prompting to autonomous multi-agent offensive frameworks. Named tools include ARTEX, CAIRN, CyberStrikeAI, and PentAGI. They run multi-stage intrusions at higher speed. Some attackers use them to build and run exploits from software patches. That speed shrinks the window defenders have to patch.
