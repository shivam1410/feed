Simon Willison converted Mozilla's MDN browser compatibility database into a ~66MB SQLite file accessible via GitHub with open CORS headers and Datasette Lite explorer. An AI-generated GitHub Actions workflow builds and force-pushes the database to an orphan branch, making it queryable across browsers. The project demonstrates how structured compatibility data becomes dramatically more accessible and searchable in SQL format, enabling developer tools to integrate browser compatibility checking and demonstrating practical value of converting specialized databases.
