A programmable world model decouples what happens in a scene (explicit state rules) from how it looks (video generation). Using executable rules and 3D bounding boxes, the model maintains persistent environmental state that users can modify programmatically. This differs from black-box video generation models where causality is implicit. The approach enables controllable, interpretable generation—users specify physics rules or object positions directly rather than hoping the model infers intent. This matters for simulation, training embodied agents, and applications requiring reliable causal relationships.
