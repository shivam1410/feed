Version 0.36 of the llm command-line tool added support for OpenAI's GPT-6 Sol and GPT-6 Luna models. Model plugins can now declare supports_conversation as false for models accepting only single-turn prompts, with llm raising a ConversationNotSupported error when multi-turn conversation history appears. Reasoning traces in markdown logs now wrap in HTML details and summary tags for cleaner output.
