An XGBoost classifier using eight clinical features (MMSE, CDR scores, MoCA, FAQ, age, sex, education) from 1,641 subjects achieves 98.2% test-set AUC detecting normal cognition, mild cognitive impairment, and Alzheimer's. Cross-validation macro AUC reached 0.983 with 94.4% accuracy. SHAP analysis identifies CDR Global as dominant predictor for cognitive status. This explainable approach delivers near-perfect three-class detection using routine assessments, directly supporting earlier diagnosis.
