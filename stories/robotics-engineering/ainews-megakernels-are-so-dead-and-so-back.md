Inference engineering debate revisits megakernels—whether GPU inference should use giant hand-fused kernels or smaller composable ones. Historically, megakernels traded two-month development overhead for launch and inter-kernel overlap savings. Recent kernel scheduling advances like Rubin address straggler CTA issues. Critics argued megakernels are dead—no serious producer uses 67k-line hand-fused production kernels. Yet counterargument shows marginal gains remain from eliminating stragglers and achieving better overall execution. The debate matters because it reflects fundamental trade-off between complexity/development time and incremental inference efficiency, with kernels evolving as hardware and scheduling improve.
