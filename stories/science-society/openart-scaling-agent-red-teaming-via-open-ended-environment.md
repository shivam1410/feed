OpenART introduces a scalable red-teaming arena with evolving stateful environments to systematically evaluate AI agent safety. The system uses the EMHA attack policy to generate increasingly difficult scenarios that expose agent failure modes. Results show that agent failure rates increase monotonically as task complexity grows, revealing that even capable agents degrade under heightened difficulty. This methodology provides a structured approach to uncovering safety vulnerabilities in long-horizon agents before deployment in real-world applications.
