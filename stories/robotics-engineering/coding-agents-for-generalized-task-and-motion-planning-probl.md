Researchers used Claude Opus 5 and Codex to write programs that solve robot planning problems generalized across different instances. Testing 980 programs on 98,000 total episodes across 28 simulated environments, the agents reached 56 to 95 percent success rates versus 47 percent for human-engineered planners. This matters because it shows AI can automate planning engineering that normally takes domain expertise.
