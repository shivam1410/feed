SWE-Game tests whether coding agents can actually build playable games with working mechanics. It covers 247 tasks across 13 gameplay types using 41 reference Godot games. Opus5 scored best overall but game-building from descriptions only reached about 50 out of 100, and executable checks matched human judgment 92.59% of the time, showing current agents struggle with gameplay logic and mechanics.
