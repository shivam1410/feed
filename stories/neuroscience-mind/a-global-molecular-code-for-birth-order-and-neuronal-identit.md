A high-resolution transcriptional atlas of the fruit fly nerve cord reveals a shared molecular code that records neuronal birth order and determines neuronal identity. Gene expression patterns act as a developmental record of when neurons were born, explaining how nervous systems generate diverse neuron types with distinct functions. This discovery illuminates how developmental timing and gene expression together create cellular diversity underlying neural circuit organization.
