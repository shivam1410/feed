SHAPER is a train-free framework that improves embodied agent performance by evolving reusable skills and a context-code harness while keeping the foundation model frozen. Rather than expensive retraining, the system leverages environment rollouts to discover and refine useful skill primitives and the code structures that organize them. This approach enables rapid adaptation to new tasks and environments without retraining the underlying neural network. By separating skill discovery from model training, SHAPER makes embodied AI more practical and efficient for real-world deployment.
